Chapter 01 · Overview

方案概览

项目背景
  • 产品定位：剑琅联盟是面向美业管理与拓客的手机端 APP，用户以小型美发店、美容院、美甲店为主，对成本高度敏感。
  • 需求来源：门店普遍在美团 / 抖音开设团购并售卖团购券，但缺少与门店管理系统的打通——核销、记账、业绩归属仍靠人工，效率低、易错漏。
  • 核心诉求：在剑琅联盟中新增美团与抖音团购核销功能，让店员用 APP 扫码即可完成验券核销，并自动生成开单记录、关联价目表与员工业绩。
方案目标
  • 完整可执行：给出从资质准备、平台入驻到技术对接、上线验收的全流程操作清单。
  • 成本透明：一次性投入、持续性成本、平台佣金分项列明，并按小规模试点与中期规模两档测算。
  • 兼顾周期与成本：结合「1 个月内上线」的紧迫需求与「成本敏感」约束，给出路径对比与推荐路线。
  • 深度打通：核销后自动生成订单 / 开单记录，关联价目表与员工业绩，形成门店经营闭环。
已确认的前提
  • 公司具备企业营业执照与对公账户，满足开放平台企业开发者资质要求。
  • 拥有自研后端团队与已有云服务器，可直接部署核销对接服务。
  • 核销场景为店员用剑琅联盟 APP 扫码核销（纯手机端，不依赖额外硬件）。
  • 核销后需自动开单、关联价目表与员工业绩（深度打通）。
  • 功能定位为免费增值能力，作为剑琅联盟的获客与粘性抓手。
  • 现有 APP 已有会员卡 / 储值等部分券能力，但无团购券核销能力，需新建。

Chapter 03 · Recommended Path

推荐路线：渐进式三步走

推荐结论
结合「1 个月内上线」的紧迫要求与「成本敏感」约束，推荐渐进式接入：第一步以 ISV 聚合快速上线验证门店需求（约 1-2 周）；第二步并行推进抖音开放平台直连，1 个月内交付自研核销能力；第三步将美团直连纳入中期规划，待二级等保认证完成后替换 ISV 美团通道，实现双平台全自研、长期成本最优。
第一阶段 · 即刻启动（第 1-2 周）
ISV 聚合快速上线
选用具备美团 + 抖音双平台官方授权的 ISV（如有赞 / 飞蛾 / 云飞 API 等），两周内让试点门店具备扫码核销能力；同步验证「核销 → 自动开单 → 业绩归因」的流程与门店接受度。此阶段目标：先跑通、再优化。
第二阶段 · 并行推进（第 2-4 周）
抖音开放平台自研直连
后端团队同步申请抖音生活服务应用与「团购核销 + 团购对账」解决方案，开发验券 / 核销 / 撤销 / 对账接口对接与自动开单联动，目标在 1 个月节点以自研能力替换抖音侧的 ISV 通道。
第三阶段 · 中期规划（1-3 个月）
美团直连与双平台收口
推进美团技术服务合作中心入驻、二级等保认证与保证金缴纳；认证完成后上线美团直连，替换 ISV 美团通道，最终以自研能力覆盖双平台，长期费用最低、控制力最强。
推荐路线的收益
  • 满足 1 个月上线的硬约束：ISV 先行保证功能可用，自研跟进不阻塞业务。
  • 成本平滑：ISV 短期年费可接受，直连后逐步退出，长期边际成本趋零。
  • 风险可控：即使美团等保周期超出预期，门店核销能力已由 ISV 兜底，不影响业务。
  • 自主可控：抖音直连与美团直连均为全自研，深度打通自动开单与业绩归因。
Chapter 04 · Path A

路径 A · 第三方 ISV 聚合（快速上线）

最快落地、前置成本最低，适合试点验证与应急兜底

接入流程

  1. 选择并核验 ISV 服务商
    优先选择同时持有美团与抖音官方授权认证的 ISV（如：有赞多平台团购统一核销、飞蛾 / 云飞 API 等聚合接口服务商）。在平台服务商名录中核验其授权资质，避免无资质中介。
  2. 商务签约与费用确认
    确认年费或按调用量计费方式、支持的平台范围、是否含自动开单 / 对账能力、售后响应等级。费用结构需白纸黑字锁定，杜绝隐性收费。
  3. 申请应用凭证与门店绑定
    在 ISV 控制台创建应用，获取 appId / appSecret；按门店维度提交美团 / 抖音门店信息，完成门店授权绑定（美团需在绑定后自动获取 appAuthToken）。
  4. 二次开发与联调
    后端团队将 ISV 核销接口接入剑琅联盟：实现验券 → 核销 → 自动开单 → 业绩归因的主链路（约 3-5 人天），并在沙箱环境完成联调。
  5. 试点上线与验收
    选取 1-2 家试点门店，店员用 APP 扫码核销真实团购券，验证核销正确性、开单联动与对账数据一致性后全量开放。

成本概览

成本项说明金额区间（行业参考）
ISV 年费 / 订阅费按门店数或按年订阅，含基础核销能力约 600-3000 元 / 店 / 年
API 调用费部分按调用量计费的服务商，超量另计按实际调用量（通常可忽略）
开发人力后端二次开发与联调（3-5 人天）自有团队，计内部工时
平台佣金美团 / 抖音对门店团购交易正常收取，ISV 不加价美团 3%-6%；抖音 3%-5% + 达人佣金
优劣势
  • 优势：上线最快（1-2 周）；免等保、免保证金、免自建后端；无需处理平台复杂资质流程。
  • 劣势：长期存在 ISV 年费；深度打通（自动开单、业绩归因、跨店规则）受 ISV 接口能力限制；依赖第三方稳定性与资质，需持续核验。
Chapter 05 · Path B

路径 B · 抖音开放平台直连（自研）

门槛适中、接口完整，1 个月内可实现，推荐作为自研首发平台

接入流程

  1. 开发者账号认证与身份绑定
    登录抖音开放平台完成企业开发者认证（免费）；在「店铺管理 → 服务应用授权」中绑定开发者身份，选择「商家自研」路径。
  2. 创建生活服务商家应用
    在开发者平台控制台创建生活服务商家应用，填写应用信息并等待审核（审核时效以平台实际为准，通常 1-7 个工作日）。
  3. 申请解决方案与接口权限
    在应用详情页申请「到综（到店综合）」解决方案，开通能力：门店管理、团购核销、团购对账；按需追加订单查询、三方码 / 预置码等能力。
  4. 商家授权与门店绑定
    引导门店在「抖音来客」完成第三方应用授权，将剑琅应用与各门店（poi_id）绑定，建立应用与门店的核销权限关系。
  5. 接口开发与联调
    按官方文档完成开发：生成 client_token 作为 access-token 鉴权；对接验券准备、验券、撤销核销、券状态查询、批量查询、对账接口；实现「核销成功 → 自动开单 → 业绩归因」联动，并按要求接入信息同步接口（避免平台强制退款无感知）。全部接口须走 HTTPS，请求头带 access-token 与 application/json。
  6. 测试验收与上线
    按「解决方案开通 → 基础配置 → 验收准备 → 测试验收 → 应用上线」顺序完成，先在沙箱 / 测试门店验证，再灰度至试点门店。

成本概览

成本项说明金额 / 费率
开发者认证与入驻抖音开放平台企业认证、应用创建免费
技术服务费订单担保交易基础费率订单金额的 0.6%
本地生活软件服务费按商品类目收取（美业类目区间）约 3%-5%
达人佣金门店若通过达人带货需另付（营销成本，非接入成本）美业常见 20%-35%
开发人力后端自研对接（约 8-12 人天）自有团队，计内部工时
服务器复用已有云服务器，新增核销服务边际成本低，见成本明细
优劣势
  • 优势：认证免费、无保证金（生活服务开发者侧）；接口完整，可自主实现全链路深度打通；长期成本最低、控制力最强。
  • 劣势：需投入后端开发（8-12 人天）；平台审核与验收有一定周期；需持续跟进接口规范与平台政策变化。
Chapter 06 · Path C

路径 C · 美团开放平台直连（自研）

门槛最高、周期最长，但美团到综团购是美业门店的重要经营阵地，值得中期投入

接入流程

  1. 服务商入驻与资质审核
    在美团技术服务合作中心（developer.meituan.com）注册并选择「三方服务商入驻」，提交企业资质（营业执照、对公账户、开发者信息、所需接口服务），完成资质审核。
  2. 签署服务协议并缴纳保证金
    审核通过后签署并邮寄盖章《服务协议》，平台按注册资本、对接业务、安全等级等评估保证金金额（通常数万元级，无违规情况合作终止后 15 个工作日内无息退还），7 个自然日内缴纳后分配开发者账号与密钥。
  3. 安全合规材料（二级等保 / 网络安全保险）
    完成《信息系统安全等级保护备案证明》二级及以上认证（建议两年一检），或购买平台认可的网络信息安全保险；部署云安全产品（如防火墙）；提交《服务商数据交互合规化承诺书》。此环节是美团侧主要的时间与成本瓶颈。
  4. 商家授权与门店绑定
    调用获取授权链接接口引导美团商家授权，绑定后自动回调获取 appAuthToken、美团门店 id 与门店名称；按业务类型配置（到综业务 businessId=5 等）。
  5. 接口开发与联调
    对接美团团购券验券、核销相关 API（申请应用信息、获取接口调用凭证、绑定门店、验券 / 核销 / 撤销），按 API 计费规则关注技术服务费；实现自动开单与业绩归因联动，处理错误码与幂等。
  6. 上线审核与验收
    上线前平台对安全资质与接口合规进行审核，通过后开放正式环境，灰度试点后全量上线。

成本概览

成本项说明金额 / 费率
服务商保证金按注册资本 / 业务 / 安全等级评估，可退还通常数万元级（以平台核算为准）
二级等保认证备案 + 测评 + 整改（两年一次）约 3-8 万元 / 次（含测评与整改，以实际报价为准）
网络安全保险（替代方案）平台认可的可替代等保的安全投入约 1-3 万元 / 年
云安全产品防火墙等安全组件（已有云环境）数百-数千元 / 年
API 技术服务费按接口类型与调用量计费以《API 计费管理规则》为准

开发人力后端对接 + 等保材料配合（约 15-20 人天）自有团队，计内部工时
优劣势
  • 优势：接口完整、全链路自主可控；美团到综团购契合中小美业门店的搜索转化场景，长期经营价值高。
  • 劣势：二级等保与数万级保证金门槛导致一次性成本高、周期长（通常 2-3 个月），与 1 个月内上线的目标冲突，故列为中期规划。
Chapter 07 · Technical Notes

技术对接要点

核心核销流程（店员视角）

  1. 扫码 / 输入券码
    店员在剑琅联盟 APP 打开「团购核销」，扫描顾客美团 / 抖音团购券码，或手动输入券码。
  2. 验券准备
    APP 调后端，后端向平台发起验券准备 / 验券查询请求，返回券状态、面额、使用次数（次卡含剩余次数）。
  3. 确认核销
    店员核对券信息后确认，后端调用平台核销接口（抖音为验券接口 + 撤销核销；美团为核销 / 撤销接口），记录核销结果并做幂等与异常重试。
  4. 自动开单
    核销成功后系统自动生成开单记录：金额、门店、渠道（美团 / 抖音）、券码关联价目表项目，按门店配置自动归因员工与业绩，店员可按需补充客户信息。
  5. 对账与撤销
    核销记录进入日常对账；顾客退款 / 撤销核销时，后端调用平台撤销核销接口并同步冲销剑琅内部开单记录。建议按平台要求接入订单信息同步接口，避免平台强制退款而本地无感知。

工程与安全要点
  • 幂等：核销请求需支持幂等（抖音 verify_token 幂等、美团按订单维度），防止重复核销。
  • 重试与补偿：平台接口异常时需重试机制；本地与平台核销状态需一致性校验，避免双方订单信息不一致。
  • 密钥安全：appSecret / SignKey 服务端保管，禁止下发客户端；接口走 HTTPS。
  • 多门店权限：按门店维度管理授权关系与核销范围，防止跨店核销或越权。
  • 次卡适配：抖音次卡需处理次数字段（总次数、已使用次数）与按次核销 / 撤销。
  • 数据合规：美团侧需提交数据交互合规承诺书并满足二级等保 / 保险要求。

Chapter 09 · Timeline

上线排期（1 个月内交付核销能力）

第 1 周
ISV 选型与签约 + 抖音应用创建
完成 ISV 资质核验与签约；同步启动抖音开放平台企业认证、创建生活服务应用、申请到综解决方案与团购核销 / 对账权限。
第 2 周
ISV 试点上线 + 抖音接口开发启动
ISV 通道完成门店绑定与联调，1-2 家试点门店上线核销；后端同步开发抖音验券 / 核销 / 撤销接口与自动开单联动。
第 3 周
抖音直连联调 + 内部验收
抖音侧完成商家授权、沙箱联调、核销 → 自动开单 → 业绩归因全链路验证；同步筹备美团入驻材料。
第 4 周
抖音直连灰度上线
抖音直连通过平台验收并在试点门店灰度；ISV 通道保留兜底，评估抖音侧替换 ISV；输出美团直连的中期立项材料（等保、保证金预算）。
关键里程碑
  • 第 2 周末：ISV 通道实现扫码核销可用（最快目标）。
  • 第 4 周末：抖音直连完成自研核销 + 自动开单 + 业绩归因，试点门店可用。
  • 1-3 个月：美团直连立项（等保 + 保证金），完成双平台自研收口。
Chapter 10 · Risks

风险与应对

美团等保 / 保证金周期超出预期
应对：美团直连列为中期规划而非上线依赖；1 个月内由 ISV 通道兜底美团侧核销，业务不受阻塞，等保完成后再迁移。
ISV 资质或服务不稳定
应对：签约前核验平台官方授权名录；锁定服务 SLA 与退出条款；渐进式路线下直连能力作为自主替代，降低长期依赖。
平台接口 / 计费政策变动
应对：关注美团《API 计费管理规则》与抖音开放平台公告；预留接口适配层，将平台差异隔离在统一核销模块内。
核销状态不一致 / 重复核销
应对：全链路幂等设计 + 平台状态预校验 + 重试与对账机制；必要时接入订单信息同步接口，及时感知平台侧强制退款。
门店对平台佣金的敏感度
应对：核销功能对门店免费，作为剑琅增值能力；在方案与门店沟通中明确「平台佣金为美团 / 抖音正常经营成本」，并展示核销自动开单带来的效率与业绩数据价值。
多门店授权与权限管理
应对：按门店维度管理平台授权、核销范围与员工业绩归因；建立授权到期提醒与异常核销告警。
